CAKE CANDLES ACTIVITY - IMAGE REQUIREMENTS
==========================================

You need to add these PNG images to the /public folder:

1. cake.png
   - Recommended size: 220x280 pixels (or similar aspect ratio)
   - Should be a birthday cake image
   - Transparent background preferred
   
2. candle.png
   - Recommended size: 60x80 pixels (or similar aspect ratio)
   - Should be a single birthday candle with flame
   - Transparent background preferred

FALLBACK:
If these images are not found, the activity will use emoji fallbacks (🎂 and 🕯️)

The activity will automatically detect and load your PNGs when you add them to the public folder.
